# Contributing to HM Wheat Farm

Thank you for considering contributing! 🎉

## 📋 Ways to Contribute

### 🐛 Bug Reports
- Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md)
- Include all requested information
- Be as detailed as possible

### ✨ Feature Requests
- Use the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md)
- Explain the use case
- Provide examples if possible

### 🔧 Code Contributions
1. Fork the repository
2. Create a feature branch (`feature/amazing-feature`)
3. Make your changes
4. Test thoroughly
5. Submit a Pull Request

## 💻 Development Guidelines

### Code Style
- Use clear, descriptive variable names
- Comment complex logic
- Follow existing code patterns
- Use DRY principle (Don't Repeat Yourself)

### Testing
Before submitting:
- [ ] Test on QBox framework
- [ ] Test on QBCore framework
- [ ] Test on ESX framework
- [ ] Test with ox_inventory
- [ ] Test with qb-inventory
- [ ] No console errors
- [ ] No performance issues

### Commits
- Use clear commit messages
- Reference issues where applicable
- One feature/fix per commit when possible

Example:
```
fix: correct mill ped Z-coordinate (#14)
feat: add tgiann-inventory support
docs: update README with new features
```

## 🔄 Pull Request Process

1. **Fork & Branch**: Create a feature branch
2. **Code**: Make your changes
3. **Test**: Thoroughly test everything
4. **Document**: Update docs if needed
5. **PR**: Submit with filled template
6. **Review**: Address any feedback
7. **Merge**: Once approved!

## 📝 Documentation

When adding features:
- Update README.md
- Update CHANGELOG.md
- Add code comments
- Update config.lua comments

## ❓ Questions?

- Check existing issues first
- Use the [Config Help template](.github/ISSUE_TEMPLATE/config_help.md)
- Join our Discord (if available)

## 🙏 Recognition

Contributors will be:
- Listed in README.md
- Mentioned in CHANGELOG.md
- Credited in commits

Thank you for helping improve HM Wheat Farm! 🌾
